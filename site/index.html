The model behind the prediction

Bayesian-tuned CatBoost, refitted on 98 development records. Eleven raw inputs generate 20 descriptors, then 23 model columns. The browser uses the same feature engineering, fitted preprocessing, and 417 trees as the verified Python pipeline.

Internal validation only

Loading verified model metrics.

Tuning and evaluation reused the development data. These scores are not external test performance and do not establish transfer to new studies or materials.

What domain screening means

A standardized distance to the development-data centroid is compared with its 95th-percentile cutoff. A point inside that cutoff is not guaranteed accurate. Input-range warnings are reported separately; predictions are never clipped to 0–100%.
